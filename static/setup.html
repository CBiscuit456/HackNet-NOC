The "Watcher" Philosophy

HackNet NOC operates as the single source of truth for your homelab. Best Practice: We highly recommend running this dashboard on an independent device. If your main hypervisor goes offline, your watcher must remain online to alert you.

Network Core Baseline

How does HackNet NOC know if your internet is offline? Define a highly available external gateway so the system can differentiate between a local node outage and an ISP failure.

Recommendation: Use your ISP Gateway IP, or a reliable DNS provider like Cloudflare (1.1.1.1).
